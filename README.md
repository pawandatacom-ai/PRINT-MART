# PRINTMART – Step 1 (Frontend)
## Run on your computer
1. Install Node.js (LTS) from https://nodejs.org
2. Open this folder in a terminal (in VS Code: Terminal > New Terminal)
3. Run: `npm install`
4. Copy `.env.example` to `.env.local` and put your WhatsApp number (with 91, no +)
5. Run: `npm run dev` and open http://localhost:3000
## Done in Step 1
Homepage, 12 categories, shop + search, product page with live pricing, file validation, working cart.
